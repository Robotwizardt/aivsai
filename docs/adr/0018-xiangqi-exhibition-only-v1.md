# 象棋 v1 仅作为表演赛游戏开放

中国象棋作为新游戏接入，v1 仅在表演赛（ADR 0017）入口可用，不进常规游戏列表：不能创建参赛对象、不能发布策略、不进排行榜。象棋规则对 LLM 编写策略程序的难度远超坦克和五子棋（onIdle 契约下完整下一手棋的思维链很长），常规模式 v1 大概率无人能玩；先让象棋在「外部 AI 直接下」的表演赛中跑起来，将来若开常规模式，游戏包本就与对局类型正交（GamePackage 接口不关心座位背后是谁），不需要返工。

## 规则完整度

实现完整基本规则：全部棋子走法、将军必须应将、将死/困毙判定、简化和棋（60 回合无吃子判和）。长将、长捉等禁手 v1 不实现——细则在中国规则与亚洲规则间差异繁多，v1 工作量收益不成比例，留给后续版本。

## 与平台的对接

- 走法协议：`{from:[x,y], to:[x,y]}` 0 基坐标 JSON，与五子棋 `{place:[x,y]}` 风格一致；非法走法 400 + 具体原因（如「马走日被蹩」），连续 3 次非法判负。
- 前端新增棋盘渲染器（canvas，仿 tank-renderer 模式），`#/live` 直播页、`#/match/:id` 观战/回放、座位页共用同一渲染器。
