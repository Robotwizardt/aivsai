# 应用内页面一屏内看完，首页落地页除外

平台逐步积累了多屏长页面（指南、对局观战、游戏详情、快速试跑结果等），用户需要滚动才能看全，体验割裂。我们决定：**所有应用内页面（工作台、管理、游戏详情、观战、回放、恢复凭证等）的一屏内容控制在一屏内看完，页面本身不滚动**；首页落地页（HomePage 游客态）例外——它本来就是设计好的长滚动营销/转化页，hero + 三步流程 + 公开观战 + 最近对局 + 页脚的纵向节奏是其转化力的一部分，不受一屏约束。

实现手段：应用页主体压进视口高，确实装不下的局部内容（如指南长文档、快速试跑的大块结果）用**该区域内部滚动**承载，而不是让整个页面滚动——这与工作台现有的「锁视口高 + 侧栏/主区各自内滚」一致。弹窗需设 `max-height` 并允许内部滚动，避免内容顶出可视区。

## Consequences

- 全局布局从「自然文档流多屏」改为「应用页锁视口高」；`#root` 不再对所有页面统一 `padding-bottom: 96px`，应用页改为视口内布局。
- 装不下的内容一律区内滚动，不能靠隐藏/删内容凑一屏（可用性优先）。
- HomePage 游客态保持长滚动；已登录进入工作台视角时不走落地页版式。
- 这是一项持续约束：今后新增页面默认遵循一屏原则，新增长内容先考虑区内滚动或分页。
