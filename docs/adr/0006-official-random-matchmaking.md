# 正式对局只能随机匹配相近积分对手，训练可指定对手

正式对局不允许指定对手，由系统在积分相近（首版默认 ±50）的候选中随机匹配；匹配不到合适对手时报错提示稍后再试，不自动放宽范围。训练对局则可以粘贴任意参赛对象 ID 指定对手（对方需有已发布策略，可跨工作台），或选择内置基准 bot。

这是对 [0004](0004-versioned-games-and-separate-rankings.md)「计分资格与重复挑战」一节的**显式修正**：0004 写的是「允许指定对手反复练习……不以只有随机匹配才能计分」，即正式对局也能指定对手。本决定把它收紧为——正式对局只能随机匹配，指定对手的练习全部归到训练对局。

## 理由

正式对局计入排行榜。若允许自选对手，玩家可以反复挑战弱对手刷分，或与自己控制的对象对局做局。改为随机匹配相近积分对手后，每一场计分对局的对手强度都与自身相当，排行榜的 Elo 积分才有意义。训练不计分，指定对手没有刷分风险，因此保留任意指定（含粘贴他人坦克 ID）作为练习手段。

## 规则细节

- **正式（official）**：调用方传任何对手字段（`opponentEntrantId` 或 `opponentBotId`）都被拒绝（400）。系统在候选池中等概率随机选取：同游戏、非自己、非同工作台、有已发布策略、与自身积分差 ≤ ±50。池为空返回 409，提示稍后再试，不放宽范围。
- **训练（training）**：必须指定对手——内置 bot（`opponentBotId`）或任意参赛对象（`opponentEntrantId`）二选一。可挑战其他工作台的坦克（对方需有已发布策略）；不能挑战自己或同工作台的另一个对象（防止自测刷数据）。
- 自己不能打自己：正式随机匹配排除自己与同工作台对象；训练指定同工作台对象也会被拒绝。
- 分差上限（±50）、初始积分（1000）、K 值（32）均为可配置的设计基线，未经过平衡性实测；匹配不到时不放宽是为了避免与实力悬殊者对局影响积分公平性。

## 对 0004 其他内容的影响

0004 中「同一无序对手组合 24 小时内最多 3 场计分」「同工作台对局不计分」等防刷机制在随机匹配下依然有效（仍可能反复匹配到同一对手），继续保留。0004 其余关于版本、回放、保留期的决定不变。
