# 响应式双端适配：900px 断点，手机端为响应式降级而非独立页面

平台 Web 界面需要同时服务电脑宽屏与手机。选择在同一套 React 代码与样式内做响应式适配：以 900px 为唯一分界，≤900px 进入手机模式，≥901px 保持宽屏模式。手机端是「响应式降级」：保证可用、不溢出、不误导，不追求与宽屏完全对等的体验。

相比为手机单独维护一套页面或组件，响应式单套让每个新功能只需实现一次，改动集中在 CSS，避免双端漂移；代价是手机端布局受桌面结构约束，复杂页面（如工作台）只能做有限重排。相比业界常见的 768px 断点，900px 与既有的一屏化断点（ADR 0011）重合，让「宽屏一屏化 / 手机自然文档流」两套机制各自完整、互不交叉；平板竖屏（768–900px）因此归入手机模式，恰好覆盖该区间此前表格溢出无滚动的空白地带。

## 断点与基础规则

- 全站断点统一为 `max-width: 900px` / `min-width: 901px`，清理 640/760/860 旧断点。
- 手机模式下输入控件（input/textarea/select）统一 16px 字号，避免 iOS Safari 聚焦时自动放大页面。
- 多列表格统一横向滚动（`.table-scroll` 包裹），不再依赖 ≤640px 的 `display:block` 兜底。
- 观战/回放 canvas 保持 612×462 固定位图，暂不做 devicePixelRatio 适配（手机上轻微模糊可接受，清晰度优化另行决策）。

## 手机模式下的页面组织

- 顶栏改两行式：第一行品牌与凭证状态，第二行导航链接横向滚动；不引入汉堡菜单等 JS 交互。
- 工作台保持「对象列表在前、主区在后」的顺序，创建参赛对象表单默认折叠为按钮，点击展开。
- 策略编辑器定位为「可看可小改」：保证打开、看清、能改几行，不为手机优化编写体验。
