# 保留游戏版本，并按版本分别排名

游戏规则或技能数值更新后发布新游戏版本，旧对局的回放保留原规则和画面版本，新旧版本的成绩分别排名。相比覆盖旧规则或延续同一排名，这个选择保留历史比赛的解释依据，避免不同规则下的成绩直接混算，但需要持续保存旧版本及其回放所依赖的内容。

旧策略须通过兼容检查才能参与新版比赛，不因游戏包升级而自动认定兼容。

## 新版启用与旧版归档

新游戏版本启用后，旧版归档，不再接收新对局；归档前已创建、仍在排队或运行中的对局继续完成。旧版历史排名和未过期回放仍可查看，归档不等于删除版本或提前清理其依赖内容。

兼容检查通过后，由管理者或获授权的外部 Agent 确认将策略用于新版，不自动迁移。相比新旧版本长期并行或自动迁移，此选择收敛日常参赛入口，同时保留参与者对新版策略发布的确认权；通过兼容检查不代表策略在新规则下仍有相同表现。

## 创建对局时固定版本

创建对局时固定游戏包、画面资源和双方策略版本，排队和比赛期间均不因新版本发布而改变。发布新策略不必等待已有比赛结束，但只影响之后创建的对局；相比开赛时才固定，这让创建时确认的参赛内容与最终执行内容一致。

## 回放读取已记录过程

回放播放已经记录的比赛过程，不重新运行策略生成历史结果，并使用该局绑定的游戏和画面版本。相比重跑策略，这使历史观看不依赖当前策略或规则的变化，代价是保存完整过程及其依赖内容；保留期限见下文。

## 排名归属与积分

同一游戏版本内，以考虑对手强度的 Elo 类积分作为主要排序依据，胜负统计另行展示。积分归属参赛对象，发布新策略版本不清零；不同游戏版本仍分别排名，不因属于同一参赛对象而跨规则版本合并成绩。相比只看胜率或累计胜场，此选择更重视对手强度，同时让持续改进策略延续该参赛对象的竞技历程。

首版默认初始积分为 1000，Elo 的 K 值为 32；这些参数可配置，修改不追溯重算既有成绩。

## 计分资格与重复挑战

同一工作台所属参赛对象之间的对局不计积分。同一游戏版本内，同一无序对手组合默认在滚动 24 小时内最多 3 场计分；交换挑战发起方不产生另一份计分额度。超过额度的挑战仍可进行并留下正式对局记录，但不再改变积分。窗口和次数可配置，修改不追溯既有成绩。

这个选择限制重复挑战对排行榜的影响，不以所有正式对局都计分。

## 历史保留与清理

首版默认正式对局的完整回放与诊断日志保留 90 天，训练的完整回放与诊断日志保留 7 天，到期清理。正式对局的结果与积分记录继续保留，界面提前显示回放到期时间。现存回放依赖的游戏版本不得提前删除；清理回放不等于删除比赛结果或逆转历史积分。

此选择以有限期保存完整过程控制持续增长的存储开销，而不是承诺永久保留全部回放。具体存储容量仍需根据实测数据确定。

## 实施前的技术验证项

版本绑定与资源依赖的具体存储方式、策略兼容检查范围、回放记录格式，以及并发比赛的计分额度判定和积分结算一致性，仍需在实施设计与验证中确定。默认积分参数是已确认的设计基线，不代表平衡性或防刷效果已经过实测。
