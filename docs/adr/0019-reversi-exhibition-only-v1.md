# 黑白棋 v1 仅开放外部 AI 表演赛

黑白棋（Reversi）作为新的游戏包接入，v1 与象棋一样仅开放表演赛：用户创建对局、分享两个座位链接，由外部 AI 直接提交行动，支持直播与回放；不开放参赛对象、策略发布、训练、正式对局或排行榜。选择复用既有座位协议而非同时开放策略程序模式，是为了将本次范围集中在外部 AI 对弈和观战体验上。

## 规则与行动契约

- 标准 8×8 棋盘，中央四子开局，黑方先手；合法落子必须在至少一个方向夹住并翻转对方棋子，所有符合条件的方向均翻转。
- 双方都没有合法落点时结束，即使棋盘未满；按棋盘现有黑白子数判胜负，同数平局，空位不额外计分。
- 行动沿用 0 基坐标 `{place:[x,y]}`。观察提供完整棋盘、当前行动方、双方子数和当前行动方的全部合法落点，使 AI 专注于策略选择；服务端仍独立校验，不信任提交方。
- 无合法落点时由游戏规则自动跳过，不要求 AI 提交 `pass`；对方若仍有合法落点，可连续行动。双方都无合法落点时直接终局，不再索取行动。
- 自动跳过不增加落子手数，不等待被跳过方、不启动其每步计时。`moveCount` 只计成功落子，初始摆子、翻转、自动跳过和非法尝试均不计入。再次轮到同一方时开始新的每步计时。

自动跳过优于显式 `pass`：无可选行动时不必额外唤起 AI 或冒无意义的超时风险。代价是不能假设双方严格交替，也不能用手数奇偶推断行动方；观察、帧、直播和回放必须保留真实行动顺序与跳过信息。

## 非法行动与计时

黑白棋每方整局累计 3 次非法行动判负，合法落子不清零；未达上限时返回具体错误并允许原方重试，每次重试重新获得完整每步时限。这沿用当前五子棋实现及座位服务的计时方式，避免本次新增游戏同时改动公共生命周期。

ADR 0017 的“连续 3 次”文字与既有五子棋实现不一致；黑白棋明确采用本 ADR 的“每方累计 3 次”，本次不改变其他游戏的错误计数规则。其余创建权限、公开/私密、暂停/恢复、解散、超时判负、无人行动自动作废和终局座位观察机制沿用既有表演赛。

## 观战

沿用现有三栏观战布局及主题、响应式布局、回放控件：左侧展示双方子数，中间展示棋盘与本手翻转高亮，右侧按真实行动顺序逐手记录落子并提示跳过。不得按固定的“两手一回合、每方一手”组织黑白棋棋谱，以免同方连续落子时漏记录。座位保持只读，不增加人工落子入口。
