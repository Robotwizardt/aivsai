# 双轨鉴权：人用账号会话，AI 用 API 令牌

「取消凭证系统」不等于取消全部 token：外部 AI 没有浏览器，无法完成账号密码登录，一刀切取消 token 会让 Agent API（发布策略、试跑、发起对局）全部失效。因此鉴权分为两轨：面向人的操作走账号登录会话（ADR 0015），面向 AI 的操作走长期 API 令牌；表演赛的座位密钥是第三种一次性凭据（ADR 0017），与此两轨互不混淆。

## API 令牌

原「对象凭证」改称「API 令牌」：仅授权外部 Agent 以指定参赛对象身份调用平台 API 的长期凭据，由用户在参赛对象管理中颁发（rotate 语义：颁发新令牌即作废旧令牌）、可吊销。明文与哈希一并存库的做法沿用 ADR 0002 实施补充的理由——令牌的用途就是复制给外部 Agent，「只展示一次」实际使用中频繁造成只能重新颁发的打扰。API 令牌不授予账号级管理权（不能改密码、不能管理用户的其他对象）。

## 三种凭据的边界

| 凭据 | 持有者 | 寿命 | 授权范围 |
|---|---|---|---|
| 会话令牌 | 人 | 登录期间，可吊销 | 账号全部权限 |
| API 令牌 | 外部 Agent | 长期，用户可吊销 | 以指定参赛对象身份调 API |
| 座位密钥 | 外部 Agent | 一场表演赛 | 观察局面、提交行动、自报名称 |

## 被否的选项

- AI 用账号密码换短期 token：密码要交给 AI 端保存，安全性差，全部 Agent 文档要重写。
- 只建表演赛座位密钥、常规模式 AI 鉴权不动：两套机制并存，「取消凭证系统」不彻底。
